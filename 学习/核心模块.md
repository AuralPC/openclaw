# OpenClaw 核心模块详解

本文档详细介绍 OpenClaw 项目的核心模块及其功能。

## 🎯 入口点模块

### 1. 主入口：index.ts

**文件**：[src/index.ts](../src/index.ts)

**职责**：
- 加载 `.env` 配置
- 规范化运行时环境
- 捕获控制台输出用于日志
- 验证 Node.js 版本（≥22.12.0）
- 构建并执行 Commander.js 程序
- 导出关键工具供库使用

**关键代码流程**：
```typescript
1. 加载环境变量（dotenv）
2. 规范化环境（normalizeEnv）
3. 设置控制台捕获
4. 验证运行时
5. 构建 CLI 程序
6. 解析并执行命令
```

**导出内容**：
- 配置加载函数
- 工具函数
- 类型定义

### 2. 进程管理：entry.ts

**文件**：[src/entry.ts](../src/entry.ts)

**职责**：
- 抑制 Node.js 实验性功能警告
- 使用正确的 `NODE_OPTIONS` 重生 CLI 进程
- 处理子进程生命周期
- Windows 下的 argv 规范化

**技术细节**：
- 检测是否需要重生进程
- 管理父子进程通信
- 处理进程退出码

### 3. 运行时环境：runtime.ts

**文件**：[src/runtime.ts](../src/runtime.ts)

**职责**：
- 运行时环境初始化
- 环境变量验证
- 平台特定配置

## 🌐 Gateway 服务器

### 1. 服务器核心

**文件**：[src/gateway/server.impl.ts](../src/gateway/server.impl.ts)

**职责**：
- HTTP/WebSocket 服务器实现
- 请求路由
- 中间件管理
- 生命周期管理

**技术栈**：
- **框架**：Hono 4.11.7
- **WebSocket**：ws 8.19.0
- **HTTP 客户端**：undici 7.20.0

**主要路由**：
```
GET  /health           - 健康检查
POST /rpc              - RPC 调用
WS   /ws               - WebSocket 连接
GET  /auth             - 认证相关
POST /chat             - 聊天接口
GET  /cron             - 定时任务状态
```

## 📝 总结

OpenClaw 的核心模块设计遵循以下原则：

1. **模块化**：每个模块职责单一、界限清晰
2. **可扩展**：通过插件和钩子系统扩展功能
3. **类型安全**：严格的 TypeScript 类型系统
4. **测试覆盖**：70% 的测试覆盖率要求
5. **性能优化**：异步处理、连接池、缓存

通过理解这些核心模块，你可以更好地掌握 OpenClaw 的工作原理，并进行定制开发。
