# OpenClaw 原型 UX 审查与优化建议

> 审查范围：prototype/ 目录下全部 13 个文件（11 HTML + 1 CSS + 1 JS）
> 审查时间：2025-02-11

---

## 做得好的地方

1. **设计系统扎实** — CSS 变量体系完备，5 级层次（L0-L5）的深色主题有电影质感，浅色主题也对应完整
2. **交互细节丰富** — 打字机效果、思考点动画、工具执行时间线、指示圆点脉冲等，给了很好的"活"的感觉
3. **Cron Builder 设计优秀** — 顶部摘要 + 快速预设 + 频率 Tab + 高级编辑，分层渐进，对非技术用户也友好
4. **侧边栏功能完整** — Tab 切换、搜索过滤、分区折叠、右键菜单、重命名、文件夹管理都有了

## 优化建议

### 一、聊天页 (chat.html)

#### 1. 消息缺少时间戳

当前消息只有内容、没有时间。长会话中用户很难判断"这条回复是什么时候的"。

**建议**：在每条消息下方添加一个淡灰小字时间戳（如"14:32"或"2 分钟前"）。

#### 2. 工具卡片摘要信息太少

"执行了 3 个工具" 没有告知用户做了什么。

**建议**：改为 "搜索 → 读取网页 → 整理内容"，让用户不用展开也能大致了解执行流程。

#### 3. 缺少消息操作菜单

目前只有复制按钮。用户可能需要：重新生成、编辑后重发、删除消息。

**建议**：hover 时出现一个 "..." 菜单，包含上述操作。

#### 4. 欢迎页快捷入口可以更具体

当前 4 个快捷入口（"帮我写代码"、"帮我写文案"等）比较泛。

**建议**：结合 Agent 技能配置，动态展示更有吸引力的具体场景描述。

#### 5. 顶栏信息密度低

topbar 只显示会话标题。

**建议**：右侧加轻量元素，如当前使用的 AI 模型标签、或本次对话的 token 用量。

---

### 二、任务页面

#### 6. task-config 缺少"下次执行时间"预览

Cron 摘要栏只显示"每天 08:00 执行"，但不显示下次具体执行时间。

**建议**：在摘要栏下方补上 "下次执行：2025-02-11 08:00"，帮助用户确认配置是否正确。

#### 7. task-config 缺少取消/删除入口

表单只有"保存配置"，没有取消编辑或删除任务的按钮。

**建议**：保存按钮左侧加"取消"（返回执行记录），底部或顶栏加"删除任务"（带确认弹窗）。

#### 8. task-history 缺少筛选和分页

3 条记录足够原型展示，但缺少筛选能力的展示。

**建议**：加一个"成功/失败"筛选按钮组，底部加"查看更多历史记录"文字链接暗示分页。

#### 9. task-history 缺少任务配置摘要

用户看执行记录时，不知道当前任务的 Cron 表达式和执行内容，需要点齿轮跳转才能看到。

**建议**：在记录列表上方加一个简洁的配置摘要条（如"每天 08:00 | 搜索今日科技新闻..."）。

---

### 三、文件管理 (files.html)

#### 10. 新建文件夹/文件用 prompt() 不够精致

当前 `createFolder()` 和 `createFile()` 用的是浏览器原生 `prompt()`，和整体深色 UI 格格不入。

**建议**：改用已有的 modal 系统（带输入框的模态框），与修改密码弹窗类似。

#### 11. 文件夹双击进入缺少视觉提示

文件夹是双击打开、文件是单击打开，但没有任何提示区分两种操作。

**建议**：文件夹行右侧加一个 ">" 箭头图标，或 hover 时显示"双击打开"提示。

#### 12. 缺少文件多选批量操作

无法一次选中多个文件做批量删除或移动。

**建议**：加 checkbox 列或支持 Shift+Click 多选，选中后显示批量操作栏。

---

### 四、设置页面

#### 13. settings-files 缺少文件内容预览模式

Agent 文件用 Markdown 编写，但编辑器只有纯文本 textarea。

**建议**：加一个"预览"按钮，用 `.md-content` 样式渲染 Markdown 预览。

#### 14. settings-skills 技能缺少详情/配置入口

点击技能只能切换开关。有配置需求的技能（如 Slack 通知需要 webhook URL）没有配置入口。

**建议**：点击技能名称可展开配置区域或跳转到技能详情页。

---

### 五、登录/注册

#### 15. login.html 缺少"忘记密码"和"记住我"

登录表单缺少这两个常见元素。

**建议**："忘记密码"可以是占位链接（点击 toast 提示"请联系管理员"），"记住我"可以是 toggle 开关。

#### 16. register.html 缺少密码强度指示器

密码字段只有"至少 6 个字符"的提示，没有强度可视化。

**建议**：加一个简单的颜色条（红/黄/绿 = 弱/中/强），提升注册体验。

---

### 六、全局体验

#### 17. 缺少加载/骨架态

页面切换是整页跳转，过程中没有过渡反馈。

**建议**：在 topbar 加一个页面加载进度条（类似 NProgress 顶部细线），用 CSS animation 模拟即可。

#### 18. 任务 tab 的空状态缺失

如果用户删除了所有任务，sidebar 任务 tab 各分区都是空的，体验突兀。

**建议**：加一个空状态提示（"暂无任务，点击'+ 新任务'创建"）。

#### 19. 侧边栏分区标题没有项目计数

"📌 置顶"、"💬 最近"等标题没有显示条目数量。

**建议**：加上计数（如"📌 置顶 (1)"、"💬 最近 (3)"），帮助用户快速评估各分区。
