# 02 - 页面设计与用户流程

---

## 一、设计方向

**整体风格**：取 ChatGPT 的简洁布局 + 飞书的交互细节，走"干净专业"路线。

**设计原则**：
- 聊天是绝对核心，占最大面积，其他功能收到侧边或二级页面
- 默认深色主题（AI 产品的主流审美），支持浅色切换
- 信息密度适中——不像 IM 那么紧凑，也不像文档那么松散
- 减少页面跳转，能在当前页面完成的就不跳走

---

## 二、导航结构

```
┌─────────────────────────────────────────────────┐
│  未登录用户可见的页面                              │
│  ┌──────────┐  ┌──────────┐                      │
│  │  登录页   │  │  注册页   │                      │
│  └────┬─────┘  └────┬─────┘                      │
│       └──────┬───────┘                            │
│              ▼                                    │
│  登录后进入主界面（单页应用，不再跳转）              │
│  ┌────────────────────────────────────────────┐  │
│  │  主界面 = 侧边栏 + 内容区                    │  │
│  │  ┌──────────┬─────────────────────────┐    │  │
│  │  │ 侧边栏    │     内容区               │    │  │
│  │  │ ·会话列表  │     ·聊天页（默认）       │    │  │
│  │  │ ·新建会话  │     ·用户设置页           │    │  │
│  │  │ ·用户菜单  │                          │    │  │
│  │  └──────────┴─────────────────────────┘    │  │
│  └────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

**关键决策**：登录后不再有传统的"多页面跳转"，而是一个主界面里切换内容区，聊天体验不被打断。

#### 侧边栏详细说明

侧边栏采用**邮箱式分区**设计，由系统自动分区 + 用户自定义文件夹组成：

| 分区 | 性质 | 说明 |
|------|------|------|
| 新聊天 / 新任务 | 操作按钮 | 顶部两个创建按钮 |
| 📂 文件 | 导航入口 | 点击进入文件系统管理页面（替换右侧内容区） |
| 搜索 | 操作入口 | 跨所有分区搜索会话和任务 |
| 📌 置顶 | 手动 | 用户主动置顶的重要会话/任务，始终在最上方 |
| 💬 最近 | 自动 | 系统自动归入最近 7 天内有活动的会话（未被归入文件夹的） |
| 📁 自定义文件夹 | 手动 | 用户自建文件夹（如"工作"、"学习"），将会话/任务拖入分类，可折叠 |
| 🗄️ 归档 | 手动 | 不想删但暂时不需要的旧会话，点击展开才看到内容 |
| 用户区 | 固定 | 底部固定，显示头像+昵称，点击展开菜单（设置、退出登录） |

**分区规则**：
- 聊天和定期任务混排在同一个列表中，用 ⏰ 图标区分定期任务
- 被放入文件夹的会话不再出现在"最近"中（避免重复）
- 未归类的活跃会话自动落在"最近"（兜底，不会丢）
- 置顶是独立标记，文件夹内的项也能置顶

**会话/任务项操作**：鼠标悬停显示操作菜单（置顶、移动到文件夹、重命名、归档、删除）

**侧边栏可折叠**：小屏幕或用户主动收起时，侧边栏折叠为窄条（仅图标），聊天区获得全部宽度。

#### 聊天区顶栏

| 元素 | 说明 |
|------|------|
| 会话标题 | 当前会话名称，可点击编辑 |
| 设置齿轮 | 当前会话的参数设置（思考级别、上下文长度等） |

#### 消息区

| 元素 | 说明 |
|------|------|
| 用户消息 | 带用户头像，纯文本或含图片 |
| AI 回复 | 左对齐，带 Agent 头像，**只显示纯文字回复**，支持 Markdown 渲染 |
| 工具聚合卡片 | AI 回复中如果有工具调用，所有工具执行聚合为**一张卡片**，显示"执行了 N 个工具"，点击展开右侧边栏 |
| 流式输出 | AI 回复中的文字逐字出现，底部显示光标闪烁效果 |
| 加载指示 | AI 开始思考时显示三个跳动圆点 |
| 复制按钮 | 鼠标悬停在 AI 回复上时，右上角出现复制按钮 |
| 停止按钮 | AI 回复过程中，输入框上方出现"停止生成"按钮 |

#### 工具聚合卡片说明

AI 的工具执行不再混在文字回复中，而是分离展示。

卡片有两种状态：

**状态一：执行中**
```
┌─────────────────────────────────┐
│ ⚙ 正在执行工具...  ●●●   [查看]  │  ← ●●● 为动态加载动画
└─────────────────────────────────┘
```
- 显示"正在执行工具..."+ 加载动画，传达"AI 在干活"
- 点击"查看"可展开右侧边栏，实时观看每个工具的执行进度
- 不点击也不影响，等执行完会自动切换到完成态

**状态二：执行完成**
```
┌─────────────────────────────────┐
│ ✅ 执行了 3 个工具        [查看]  │
└─────────────────────────────────┘
```
- 显示完成标记 + 工具总数
- 点击"查看"展开右侧边栏，查看完整的执行链路和结果

**右侧边栏（展开态）**：
- 点击工具卡片后，从右侧滑出详情面板
- 展示完整的工具执行链路，按执行顺序纵向排列
- 每个工具节点显示：序号 → 工具名称 → 输入参数 → 执行状态 → 输出结果
- 执行中的工具实时更新（流式渲染）
- 已完成的工具结果支持 Markdown 渲染，长结果可折叠
- 顶部有关闭按钮，点击或按 Esc 关闭侧边栏

**三栏布局规则**：
- 右侧边栏展开时，聊天区宽度自动压缩，三栏共享屏幕
- 右侧边栏可拖拽调整宽度
- 切换到其他会话时，右侧边栏自动关闭

#### 输入区

| 元素 | 说明 |
|------|------|
| 文本输入框 | 自适应高度，Enter 发送，Shift+Enter 换行 |
| 发送按钮 | 输入框右侧，有内容时高亮可点击 |
| 附件按钮 | 支持粘贴图片或点击上传 |
| 图片预览 | 已添加的图片在输入框上方显示缩略图，可移除 |

- **手动执行**：底部按钮可触发一次立即执行，方便调试

## 四、用户流程

### 4.1 首次使用流程

```
打开网站
  │
  ▼
看到登录页 ──→ 点击"去注册" ──→ 注册页
  │                               │
  │                          填写信息并注册
  │                               │
  │                          注册成功，自动登录
  │                               │
  ▼                               ▼
输入账号密码登录 ─────────────→ 进入主界面
                                  │
                             看到空状态欢迎页
                                  │
                             点击快捷入口 或 直接输入
                                  │
                             自动创建第一个会话
                                  │
                             开始与 AI 对话
```

### 4.2 日常使用流程

```
打开网站
  │
  ▼
自动登录（JWT 未过期）
  │
  ▼
进入主界面，显示上次的会话
  │
  ├──→ 继续上次对话（直接输入）
  │
  ├──→ 切换会话（点击侧边栏其他会话）
  │
  ├──→ 新建聊天（点击"新聊天"按钮）
  │
  ├──→ 新建定期任务（点击"新任务"按钮）
  │
  └──→ 进入设置（点击用户头像 → 设置）
```

### 4.3 一次完整对话的流程

```
用户在输入框打字
  │
  ├─ 可选：粘贴/上传图片 → 显示预览
  │
  ▼
按 Enter 或点击发送
  │
  ▼
用户消息立即出现在消息区（乐观更新）
  │
  ▼
出现"正在思考..."指示器
  │
  ├──→ 如果 AI 调用工具：
  │      消息中出现聚合卡片"执行了 N 个工具 ⏳"
  │      卡片实时更新执行进度
  │      用户可点击卡片展开右侧边栏，查看完整执行链路
  │
  ▼
AI 回复逐字出现（流式输出，只有纯文字，不混入工具内容）
  │
  ├──→ 用户可以随时点击"停止生成"
  │
  ▼
回复完成，显示复制按钮
  │
  ▼
用户可以继续输入下一条消息
```

### 4.4 会话管理流程

```
新建聊天：
  点击"新聊天" → 进入空状态 → 发送消息 → 会话出现在侧边栏"聊天"分区

删除会话/任务：
  鼠标悬停会话项 → 出现删除图标 → 点击 → 确认对话框 → 删除
  → 如果删的是当前会话，自动切换到上一个会话

重命名会话/任务：
  鼠标悬停会话项 → 出现编辑图标 → 点击 → 标题变为可编辑 → 回车保存
```

### 4.5 定期任务流程

```
新建任务：
  点击"新任务"
    │
    ▼
  右侧显示空白任务配置面板
    │
    ▼
  填写任务名称、执行周期、执行内容
    │
    ▼
  点击"保存配置"
    │
    ▼
  任务出现在侧边栏"定期任务"分区
  右侧自动切换到执行记录视图（暂无记录）
    │
    ▼
  可点击"手动执行一次"立即测试

查看已有任务：
  点击侧边栏任务项 → 右侧显示执行记录（按时间倒序）
  → 每条记录可展开查看 AI 完整回复

修改任务配置：
  在任务执行记录视图 → 点击顶栏设置齿轮
  → 切换到配置面板 → 修改后保存 → 自动回到执行记录

暂停/启用任务：
  进入任务配置面板 → 切换"启用/暂停"状态 → 保存
```

|--------|------|

| Esc | 停止生成 / 关闭弹窗 |

- 默认深色：深灰背景（#1a1a2e 或类似）、浅色文字
- 浅色可选：白色背景、深色文字
- 切换时平滑过渡（CSS transition）

| 工具聚合卡片 | 聚合显示"执行了 N 个工具"，点击展开右侧边栏查看完整执行链路 |
