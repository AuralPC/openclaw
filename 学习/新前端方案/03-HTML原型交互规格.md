# 03 - HTML 原型交互规格

> 本文档定义每个原型页面需要实现的交互效果，作为开发 HTML 原型的依据。

---

## 一、全局规格

### 1.1 技术约束

- 纯 HTML + CSS + JavaScript，无框架依赖
- 所有页面可通过浏览器直接打开（file:// 协议）
- 共享一个 CSS 文件（style.css）确保风格统一
- 共享一个 JS 文件（interactions.js）实现通用交互

### 1.2 视觉规格

| 项目 | 值 |
|------|-----|
| 默认主题 | 深色 |
| 背景色 | #1a1a2e（主区域）、#16162a（侧边栏） |
| 强调色 | #4f46e5（蓝紫色，按钮、链接、选中态） |
| 文字色 | #e2e8f0（主文字）、#94a3b8（次要文字） |
| 成功色 | #22c55e |
| 错误色 | #ef4444 |
| 警告色 | #eab308 |
| 字体 | system-ui, -apple-system, sans-serif |
| 代码字体 | 'JetBrains Mono', 'Fira Code', monospace |
| 圆角 | 8px（卡片）、6px（按钮）、4px（输入框） |
| 过渡时间 | 200ms（默认）、300ms（面板滑入/滑出） |

### 1.3 全局交互

| 交互 | 说明 |
|------|------|
| 深色/浅色切换 | 所有页面右上角或设置中可切换，CSS 变量实时切换 |
| 响应式 | ≤768px 时侧边栏隐藏，显示汉堡菜单按钮 |

## 二、各页面交互清单

### 2.1 登录页（login.html）

| 交互 | 实现方式 |
|------|----------|
| 输入框 focus 样式 | CSS :focus，边框变为强调色 |
| 回车提交 | JS keydown 监听 |
| 登录按钮点击 | 模拟 loading 状态（按钮显示转圈 1 秒），然后跳转到 chat.html |
| 登录失败模拟 | 如果密码输入"error"，显示红色错误提示 |
| "去注册"链接 | 跳转到 register.html |

### 2.2 注册页（register.html）

| 交互 | 实现方式 |
|------|----------|
| 实时校验 | 用户名 <3 字符、邮箱格式错误、密码 <6 字符、两次密码不一致时，对应输入框下方显示红色提示 |
| 注册按钮 | 全部校验通过时按钮高亮可点击，否则置灰 |
| 注册成功 | 模拟 loading 1 秒后跳转到 chat.html |
| "去登录"链接 | 跳转到 login.html |

### 2.3 聊天主页（chat.html）

这是交互最密集的页面。

#### 侧边栏

| 交互 | 实现方式 |
|------|----------|
| 侧边栏折叠/展开 | 点击折叠按钮，侧边栏宽度从 240px 动画收缩到 0，聊天区扩展到全宽 |
| 新聊天按钮 | 清空消息区，显示空状态欢迎页 |
| 新任务按钮 | 跳转到 task-config.html |
| 文件按钮 | 跳转到 files.html |
| 搜索框 | 点击展开搜索输入框，输入时实时过滤下方会话列表（前端过滤预置数据） |
| 分区折叠 | 📌置顶、💬最近、📁文件夹、🗄️归档 的标题可点击折叠/展开 |
| 会话项点击 | 高亮选中态，右侧消息区切换为对应会话的模拟消息 |
| 会话项 hover | 鼠标悬停显示操作图标（置顶、重命名、归档、删除） |
| 会话项右键菜单 | 右键弹出操作菜单（与 hover 操作一致） |
| 删除确认 | 弹出确认对话框 |
| 重命名 | 会话标题变为可编辑的 input，回车保存，Esc 取消 |
| 用户菜单 | 底部用户区点击展开下拉菜单（设置、退出登录） |

#### 消息区

| 交互 | 实现方式 |
|------|----------|
| 预置消息 | 页面加载时已有 3-4 条模拟对话（用户消息 + AI 回复） |
| 流式输出模拟 | 发送消息后，AI 回复以打字机效果逐字出现（每 30ms 一个字符） |
| 思考指示器 | 发送消息后先显示三个跳动圆点（CSS animation），1 秒后开始打字 |
| Markdown 渲染 | AI 回复中包含模拟的标题、代码块、列表，用 CSS 美化展示 |
| 代码块 | 带深色背景、语法高亮色、右上角复制按钮和语言标签 |
| 复制按钮 | 鼠标悬停在 AI 消息上时右上角出现，点击显示"已复制"提示 |
| 消息滚动 | 新消息出现时自动滚动到底部 |
| 工具聚合卡片 — 执行中 | 预置一条 AI 回复前有"⚙ 正在执行工具... ●●●"卡片，3 秒后自动切换为完成态 |
| 工具聚合卡片 — 完成 | 显示"✅ 执行了 3 个工具 [查看]" |
| 停止按钮 | 流式输出期间，输入框上方显示"停止生成"按钮，点击中止打字效果 |

#### 工具执行右侧边栏

| 交互 | 实现方式 |
|------|----------|
| 打开 | 点击工具卡片的"查看"，右侧面板从右侧滑入（300ms） |
| 关闭 | 点击关闭按钮或按 Esc，面板滑出 |
| 布局压缩 | 面板打开时聊天区宽度动画收缩 |
| 执行链路 | 面板内显示 3 个工具节点，纵向排列 |
| 实时模拟 | 打开面板时，第 3 个工具节点从"⏳ 执行中"动画变为"✅ 完成"（2 秒后） |
| 拖拽调宽 | 面板左侧边缘可拖拽调整宽度 |

#### 输入区

| 交互 | 实现方式 |
|------|----------|
| 自适应高度 | 文本框随输入内容自动增高（最大 5 行） |
| Enter 发送 | 按回车发送消息，消息出现在消息区，输入框清空 |
| Shift+Enter 换行 | 插入换行而不发送 |
| 发送按钮 | 有内容时高亮可点击，空内容时置灰 |
| 图片粘贴 | 粘贴图片后，输入框上方出现缩略图预览条 |
| 图片预览 | 缩略图右上角有 × 按钮可移除 |
| 附件按钮 | 点击触发文件选择对话框 |

#### 空状态欢迎页

| 交互 | 实现方式 |
|------|----------|
| 快捷入口 | 4 个提示卡片，hover 有浮起效果 |
| 点击快捷入口 | 文字填入输入框并自动发送，触发打字机效果 |

### 2.4 定期任务 — 配置面板（task-config.html）

| 交互 | 实现方式 |
|------|----------|
| 共享侧边栏 | 与 chat.html 相同的侧边栏，任务项高亮 |
| 执行周期下拉 | 预设选项（每小时、每天、每周等）+ 自定义 Cron 输入框切换 |
| 启用/暂停切换 | 单选按钮组，切换有颜色变化 |
| 保存按钮 | 内容有修改时高亮，点击后模拟保存成功提示（toast），然后跳转到 task-history.html |
| 设置齿轮 | 已在配置页，齿轮按钮高亮态 |

### 2.5 定期任务 — 执行记录（task-history.html）

| 交互 | 实现方式 |
|------|----------|
| 共享侧边栏 | 同上 |
| 执行记录卡片 | 预置 3 条记录（2 成功 1 失败），默认折叠 |
| 展开/折叠 | 点击记录卡片或"展开全文"按钮，展开显示 AI 完整回复（带动画） |
| 手动执行按钮 | 点击后显示"正在执行..."loading 态，2 秒后顶部新增一条"刚刚执行"的记录 |
| 设置齿轮 | 点击跳转到 task-config.html |

### 2.6 文件系统管理（files.html）

| 交互 | 实现方式 |
|------|----------|
| 共享侧边栏 | 同上，"📂 文件"按钮高亮 |
| 面包屑导航 | 点击上级目录跳回（模拟切换 div） |
| 进入文件夹 | 双击文件夹行，文件列表内容切换为子目录内容 |
| 排序 | 点击列头（名称/大小/时间）切换排序方向 |
| 文件项 hover | 背景色变化 + 右侧出现操作图标 |
| 右键菜单 | 文件项上右键弹出操作菜单 |
| 删除确认 | 弹出确认对话框 |
| 重命名 | 文件名变为可编辑 input |
| 拖拽上传 | 拖文件到列表区域时，出现蓝色虚线边框 + "释放以上传"遮罩层 |
| 上传按钮 | 触发文件选择对话框 |
| 新建文件夹 | 弹出输入框，输入名称后在列表顶部新增一行 |
| 点击文本文件 | 跳转到 file-edit.html（或切换视图） |
| 点击图片文件 | 显示图片预览遮罩层（lightbox 效果） |
| 存储用量条 | 底部进度条，静态展示 |

### 2.7 文件编辑器（file-edit.html）

| 交互 | 实现方式 |
|------|----------|
| 返回按钮 | 跳转回 files.html |
| 编辑区 | textarea 全高度，等宽字体 |
| 保存按钮 | 内容修改后按钮高亮，点击显示"已保存"toast |
| 下载按钮 | 模拟下载（可用 Blob URL 实现真实下载） |

### 2.8 设置页 — 个人设置（settings.html）

| 交互 | 实现方式 |
|------|----------|
| Tab 切换 | 顶部三个 Tab 按钮，点击切换内容区（带底部指示条滑动动画） |
| 主题切换 | 点击深色/浅色/跟随系统，整个页面实时切换主题色 |
| 修改密码 | 点击弹出模态框，含旧密码 + 新密码 + 确认密码 |
| 头像更换 | 点击触发文件选择，选择后预览更新 |
| 退出登录 | 跳转到 login.html |

### 2.9 设置页 — Agent 文件（settings-files.html）

| 交互 | 实现方式 |
|------|----------|
| 共享 Tab 栏 | 三个 Tab，"Agent 文件"激活 |
| 文件列表 | 左侧文件名列表，点击切换右侧编辑器内容 |
| 当前文件高亮 | 选中的文件名高亮 |
| 编辑区 | textarea，预填模拟内容 |
| 保存/重置 | 修改后按钮高亮，保存弹 toast，重置恢复原始内容 |
| 未创建文件 | 标记灰色 + "未创建"标签 |

### 2.10 设置页 — Agent 技能（settings-skills.html）

| 交互 | 实现方式 |
|------|----------|
| 共享 Tab 栏 | 三个 Tab，"Agent 技能"激活 |
| 技能开关 | 每个技能后面的 toggle 开关，点击切换 ON/OFF，开关有动画 |
| 计数更新 | 切换开关后，顶部"已启用 X / Y"数字实时更新 |
| 分组折叠 | 技能分组标题可点击折叠/展开 |
| 搜索过滤 | 输入关键词实时过滤技能列表 |
| 全部启用/禁用 | 一键切换所有开关 |
| 保存按钮 | 有变更时高亮，点击弹 toast |
| 依赖警告 | 缺少依赖的技能显示黄色警告条 |

## 三、通用组件交互

以下组件在多个页面复用：

### 3.1 Toast 提示

- 从顶部中央滑入，2 秒后自动滑出消失
- 类型：成功（绿色）、错误（红色）、信息（蓝色）

### 3.2 确认对话框

- 半透明遮罩层 + 居中白色卡片
- 标题 + 描述 + 取消/确认按钮
- 点击遮罩层或按 Esc 关闭

### 3.3 下拉菜单

- 触发元素点击后向下展开
- 点击菜单项执行操作并关闭
- 点击外部区域关闭

### 3.4 右键菜单

- 鼠标右键触发，出现在鼠标位置
- 交互同下拉菜单

### 3.5 Loading 按钮

- 点击后文字替换为转圈动画
- 操作完成后恢复原始文字

## 四、HTML 原型文件清单

```
prototype/
├── index.html              ← 入口，跳转 login.html
├── login.html              ← 登录
├── register.html           ← 注册
├── chat.html               ← 聊天主页（含空状态）
├── task-config.html        ← 定期任务 — 配置面板
├── task-history.html       ← 定期任务 — 执行记录
├── files.html              ← 文件系统管理
├── file-edit.html          ← 文件编辑器
├── settings.html           ← 设置 — 个人设置
├── settings-files.html     ← 设置 — Agent 文件
├── settings-skills.html    ← 设置 — Agent 技能
├── css/
│   └── style.css           ← 全局样式
└── js/
    └── interactions.js     ← 全局交互逻辑
```
